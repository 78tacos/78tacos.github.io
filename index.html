CANtrol Center

Capstone/senior project, built as a team: UI design and the server backend. CANServer is a multi-threaded TCP server and client for scheduling cansend on Linux CAN and vCAN (C++20, a thread pool, and raw sockets with cansend fallbacks). DBC File Viewer is the Qt/QML frontend, co-developed with dnasso/DBCFileViewer.

CAN-Dashboard

Web dashboard for CAN data from an electric train. It shows speed, battery, voltage, current, temperature, fan speed, power, and odometer, plus a map of a Harrisburg–Pittsburgh route. The page can simulate those values, and it can apply frames from a SocketCAN bus over a WebSocket.
